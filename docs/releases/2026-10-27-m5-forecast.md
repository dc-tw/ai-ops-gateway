# M5：共享模型版本、逐呼叫遙測與 plan-forecast

日期：2026-10-27。M5 核心交付完成；M6–M9 與 M2 剩餘治理仍未完成。

## 實作

- 新增預設關閉的 model publication／telemetry／forecast flags。
- 管理者以 CAS 發布 allowlisted route 的 provider disclosure；publication 與 calibration 均保存
  immutable revisions、current pointer、content hash 與 audit event。
- BudgetedModel 每次成功／失敗呼叫記錄安全 telemetry；有 profile 時另記逐呼叫 estimate 與
  provider actual 差值，不保存 prompt／response。Worker 對
  Workflow 使用已接受的 publication，對一般 Goal 在呼叫前解析 current publication。
- 校正只能由 admin 明確啟動，只讀既有成功 provider-reported 樣本；不足回 unknown，零 provider
  call。簡單經驗分位數不宣稱信賴區間。
- forecast 只接受 plan mode、current complete revision 及 root 明確 `plan-forecast` binding；重用
  同一 compiled Workflow，建立逐 node call manifest、情境 token 與受 DAG／parallelism／Agent
  capacity 約束的 model-only makespan。
- queue／tool／approval wait 各自保持 unknown；額度與 deadline 超限列風險，不裁切數字後宣稱可完成。
- artifact 依 plan／snapshot／compiled／calibration fingerprint 去重，發布前在同一 CAS 重查
  mode/version、Agent／Skill epoch、publication 與 calibration；讀取與去重路徑都驗證內容 hash
  及含建立者中繼資料的 record hash。
- 一般失敗、task cancellation 與消費者關閉 model stream 都會留下不含 prompt／response 的失敗
  telemetry；中斷呼叫不會被當成成功校正樣本。

## 驗證

- Ruff、compileall、shell syntax、`git diff --check`：通過。
- 真實 Redis 8.2＋Postgres 17 全量回歸：**891 passed、0 skipped**，259.55 秒；8 個既有
  RedisSaver deprecation warnings。

  **12 秒**；同一 Worker 串行為 **17 秒**，證明不是 naive sum 或無限平行。
- `./scripts/test_forecast_stack.sh`：真實 HTTP／Redis／worker，6 次 synthetic provider-reported
  calls；先 `insufficient_calibration`，明確校正後 `estimated`，相同來源 dedup，forecast 前後
  telemetry 數不增加，並驗證校正後逐呼叫 actual-minus-estimated；publication 換版後舊 session
  409。測試 stack 已自動移除 volume/network。

## 限制

- 模型／tokenizer／runtime ID 是管理者 disclosure，不是遠端 attestation。
- Profile 是既有樣本的經驗情境；尚未做真實模型 held-out accuracy／漂移校正或 production SLA。
- Forecast 不含 queue、工具與人工等待，故不是 calendar ETA；unknown 不填 0。
- Telemetry 目前是有限 Redis stream；Postgres 搜尋／retention／poison repair 屬 M6。
- Forecast SSE、OIDC 管理台與 presence 屬 M7；ACP 屬 M8；staging 1／4／16 負載、PITR、
  upgrade／rollback 與真實模型品質證據屬 M9。
