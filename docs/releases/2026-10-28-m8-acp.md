# 2026-10-28 M8：ACP v1 stdio adapter

## 完成內容

- 使用官方 `agent-client-protocol` Python SDK `0.12.x` 實作 ACP v1 stdio Agent。
- 支援 initialize、new／load session、prompt／session update、set mode、cancel。
- 新增租戶範圍的 Redis ACP session metadata、conversation owner ACL、history replay 與 mode CAS。
- token、tool status、逐次 permission、completion、error 與 cancellation 映射到 ACP schema。
- allow-once／reject-once 沿用既有 Gateway approval；Agent identity 仍不能作人類核准。
- 啟動 credential 不進 protocol；client capability 不開放 filesystem、terminal 或 MCP。
